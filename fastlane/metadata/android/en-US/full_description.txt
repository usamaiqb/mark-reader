MarkReader is an offline Markdown reader and viewer for Android. Open any .md file or source code file and read it the way it was meant to look, then write and edit Markdown notes with the built-in editor.

READ MARKDOWN
• Clean rendering styled after VS Code's Markdown preview
• Tables, task lists, math (KaTeX) and Mermaid diagrams
• Table of contents, in-document search, and a rendered/source toggle
• Export to PDF or HTML

READ CODE
• Syntax highlighting for dozens of languages, including Kotlin, Python, JavaScript, Rust, Java, C++, JSON and YAML

WRITE NOTES
• Markdown editor with live preview and a formatting toolbar
• Save in place or Save As; your notes stay ordinary .md files

PRIVATE BY DESIGN
• Works fully offline, with no internet permission
• No ads, no tracking, no account
• No storage permission: it opens only the files you choose

Material You with dynamic color and dark mode. Free and open source (GPLv3), available in 17 languages.
