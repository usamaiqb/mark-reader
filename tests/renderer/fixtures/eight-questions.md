# 数学练习（离线回归样例）

1. 函数 f(x) = \ln x - \left(\frac{1}{e}\right)^x = \ln x - e^{-x} 的定义域为 (0, +\infty)。求其单调区间。

2. 已知 \alpha 为第三象限角，且 \sin\alpha < 0，求 \cos\alpha 的符号。

3. 已知 $a^2+b^2=1$，求 $a+b$ 的最大值。

4. 计算下列积分：

   $$
   \int_0^1 x^2\,dx = \frac{1}{3}
   $$

5. 若 \( x^2 - 2x + 1 = 0 \)，求实数 x。

6. 证明：

   \[
   \sum_{k=1}^{n} k = \frac{n(n+1)}{2}
   \]

7. 求 \sqrt{2} 与 \frac{3}{2} 的大小关系。代码 `\alpha` 不应排版，售价 $5 和 $10 不应识别为公式。

8. 已知向量 \vec{a} = (1, 2)，求其模。参考 [普通链接](https://example.org/math?q=alpha)，保留原网址。
